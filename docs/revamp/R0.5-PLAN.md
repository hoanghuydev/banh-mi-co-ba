# R0.5 — Plan triển khai: cốt truyện, màn vào game, điện thoại

> Đề bài: `00-YEU-CAU.md` T0.5.1–T0.5.9. Plan này chỉ flow chính + chỗ cần chốt.

## 1. Flow mới

```
Boot → Menu (tên mới, hình quán)
  └ Chơi mới → Intro = app Message (sếp 23h → đơn nghỉ → nhóm chat → mẹ → ký thuê → đặt tên quán)
       → Ngày 1: hướng dẫn (ốp la, rửa tay mỗi 10 ổ, mở điện thoại)
Trong ngày / buổi tối: Tab → Điện thoại → [Note · Message · Đánh giá]
Đạt điều kiện → tin nhắn mới (badge) → trả lời: cảm ơn / cà khịa / không cần trả lời
```

## 3. Cần chốt

| # | Câu hỏi | Đề xuất |
|---|---|---|
| C1 | **App Note chứa gì?** ✅ đơn giản: lời bao nhiêu, bao nhiêu khách, bỏ bớt phần sổ cũ. ✅ **không** hảo cảm CANON đã khai tử sổ tay (trang đoán khách theo quan hệ) | Note = **nhật ký từng ngày** (bán bao nhiêu, lỗi gì — lấy cột log hiện có) + **note người chơi tự gõ**. Bỏ trang đoán khách |
| C2 | ✅ **Gỡ sạch cô Ba toàn game** (bù tiền, rổ ngày 1, đốt vía, lò "của cô Ba", lời thoại, công cụ tiếp khách). Hết tiền → **thua**. Ngày 1 tự nhập hàng, hướng dẫn **bắt buộc**. Lò than **không bán được**. ~~Gỡ cô Ba tới đâu?** Có ~70 file, nhiều chỗ là cơ chế kinh tế (bù tiền than, đốt vía, nghĩa vụ) | R0.5 gỡ **mọi chữ cô Ba/xe ở màn vào game, hướng dẫn, điện thoại, menu, ending**. Cơ chế kinh tế gắn cô Ba gỡ ở R3/R5 khi đụng kinh tế. Hệ quả: buổi tối/thoại NPC còn sót chữ cô Ba tới phase đó |
| C3 | **Ai dẫn hướng dẫn?** Hết mentor | ✅ **"Hệ thống Bán Bánh Mì" thức tỉnh** — giọng hệ thống kiểu truyện mạng, giao nhiệm vụ từng bước |
| C4 | ✅ **Tên người chơi:** intro cũ hỏi tên người chơi | Bỏ hỏi tên người (cố định Phương Anh) → hỏi **tên quán** |
| C5 | **Giọng tin nhắn** (sếp, đồng nghiệp, mẹ) | ✅ **Duyệt chữ trước khi code** |
